completion, completes, the emits family and throwsA on a future check asynchronously. In a widget test the code runs in a fake-async zone that only moves forward when the test pumps, so expect(future, completion(...)) may settle after the test has ended, or never. Only widget tests are checked: a plain test waits for an async matcher on its own.

Noncompliant code example

testWidgets('loads items', (tester) async {
  expect(repo.load(), completion(isNotEmpty)); // Noncompliant
});

Compliant solution

testWidgets('loads items', (tester) async {
  await expectLater(repo.load(), completion(isNotEmpty));
});
