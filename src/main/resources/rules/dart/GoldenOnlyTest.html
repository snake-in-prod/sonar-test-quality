A widget test whose only check is matchesGoldenFile fails with a pixel diff that does not say what broke, and checks nothing on the platforms where goldens are skipped or regenerated. Add at least one expectation on what the widget shows. Tests that pass the tester to a local helper are left alone, since the helper may hold those checks.

Noncompliant code example

testWidgets('home screen', (tester) async {
  await tester.pumpWidget(const App());
  await expectLater(find.byType(App), matchesGoldenFile('home.png')); // Noncompliant
});

Compliant solution

testWidgets('home screen', (tester) async {
  await tester.pumpWidget(const App());
  expect(find.text('Welcome'), findsOneWidget);
  await expectLater(find.byType(App), matchesGoldenFile('home.png'));
});
