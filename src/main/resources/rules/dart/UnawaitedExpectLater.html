expectLater returns a future that completes when the matcher has checked the value. A widget test runs in a fake-async zone and tears the widget tree down when its body returns, so an expectLater called as a statement without await (a golden comparison, a stream or future matcher) may check after the test has ended, against a tree that is gone, or not at all. Only widget tests are checked: a plain test waits for an async matcher on its own, and subscribing with expectLater before adding events is the usual way to test a stream there.

Noncompliant code example

testWidgets('home page', (tester) async {
  await tester.pumpWidget(const App());
  expectLater(find.byType(App), matchesGoldenFile('home.png')); // Noncompliant
});

Compliant solution

testWidgets('home page', (tester) async {
  await tester.pumpWidget(const App());
  await expectLater(find.byType(App), matchesGoldenFile('home.png'));
});
