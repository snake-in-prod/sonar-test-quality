expectLater returns a future that completes when the matcher has checked the value. Called as a statement without await, the test goes on (and may end) before the check runs, and a failure shows up late, in another test, or not at all.

Noncompliant code example

test('emits the value', () {
  expectLater(controller.stream, emits(1)); // Noncompliant
  controller.add(1);
});

Compliant solution

test('emits the value', () async {
  final check = expectLater(controller.stream, emits(1));
  controller.add(1);
  await check;
});
