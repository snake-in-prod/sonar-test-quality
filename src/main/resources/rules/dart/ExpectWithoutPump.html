A gesture or key event (tap, longPress, drag, fling, sendKeyEvent) changes state but builds no frame. An expect with a finder matcher right after it, with no pump in between, looks at the widget tree from before the action.

Why is this an issue?

findsNothing then passes whatever the action does, and findsOneWidget fails on a working screen. Pump a frame (or settle the animations) before checking what the action changed.

Noncompliant code example

await tester.tap(find.byKey(saveKey));
expect(find.text('Saved'), findsOneWidget); // Noncompliant

Compliant solution

await tester.tap(find.byKey(saveKey));
await tester.pump();
expect(find.text('Saved'), findsOneWidget);
