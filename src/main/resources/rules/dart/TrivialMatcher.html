An expectation that cannot fail checks nothing: anything or isA<dynamic>() match every value, a find.* finder or a constructor call is never null, a constant checked against itself (expect(true, isTrue)) and a value compared with itself always pass.

Noncompliant code example

expect(find.byKey(const Key('save')), isNotNull); // Noncompliant
expect(parse('1'), anything); // Noncompliant

Compliant solution

expect(find.byKey(const Key('save')), findsOneWidget);
expect(parse('1'), 1);
