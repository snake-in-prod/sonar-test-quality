A WidgetTester action such as tap, enterText, pump or pumpWidget returns a future. Called without await, the test goes on before the action is done.

Why is this an issue?

The expectations that follow check the screen as it was before the action, so the test can pass while the feature is broken, or fail at random. Flutter also reports overlapping guarded calls when the next tester call starts too early.

Noncompliant code example

tester.tap(find.byKey(saveKey)); // Noncompliant
await tester.pump();
expect(find.text('Saved'), findsOneWidget);

Compliant solution

await tester.tap(find.byKey(saveKey));
await tester.pump();
expect(find.text('Saved'), findsOneWidget);
