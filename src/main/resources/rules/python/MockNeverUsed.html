A mock passed by @patch, bound by with patch(...) as m or created with Mock() / mocker.patch(...) that the test never mentions again.

Why is this an issue?

The test does not check how the code used the patched dependency, and a created mock nobody receives is dead code. When the patch only stubs a side effect, name the argument with a leading underscore to say so. A patch given return_value= or side_effect= is taken as a stub on purpose.

Noncompliant code example

@patch("app.mail")
def test_signup(mail):
    assert signup("a@b.c")

Compliant solution

@patch("app.mail")
def test_signup(mail):
    assert signup("a@b.c")
    mail.send.assert_called_once()
