A test that ends with return a == b instead of assert a == b passes whatever the comparison gives: the runner ignores the returned value (recent pytest versions only warn).

Why is this an issue?

The test checks nothing. Returns inside nested helper functions, conditional expressions and tests that other code of the file calls are not reported.

Noncompliant code example

def test_sum():
    return add(1, 2) == 3  # Noncompliant

Compliant solution

def test_sum():
    assert add(1, 2) == 3
