patch("lib.clock.now") replaces the name now in lib.clock. A module that did from lib.clock import now holds its own reference to the original function and keeps calling it.

Why is this an issue?

The code under test is not patched: the test runs the real dependency and checks a mock nobody calls.

Noncompliant code example

# app.py: from lib.clock import now
@patch("lib.clock.now")
def test_run(now): ...

Compliant solution

@patch("app.now")
def test_run(now): ...
