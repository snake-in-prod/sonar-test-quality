pytest collects functions whose names start with test and classes whose names start with Test (without an __init__); unittest runs methods starting with test. A function with assertions named otherwise is never run.

Why is this an issue?

The test looks like it protects the code but never executes. Only functions that cannot be helpers are reported: no parameters, no decorator, not referenced anywhere in the project, in a file that has collected tests. Setup and teardown methods and pytest hooks are ignored.

Noncompliant code example

def check_login():  # Noncompliant
    assert login()

class TestOrders:
    def __init__(self):  # Noncompliant
        self.orders = []

    def test_empty(self):
        assert not self.orders

Compliant solution

def test_login():
    assert login()

class TestOrders:
    def setup_method(self):
        self.orders = []

    def test_empty(self):
        assert not self.orders
