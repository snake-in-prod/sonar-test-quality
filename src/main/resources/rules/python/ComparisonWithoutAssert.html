A statement that is only a comparison (==, !=, <, is, in...) computes a result and drops it. Usually the assert keyword was forgotten.

Why is this an issue?

The line looks like a check but can never fail. Comparisons used for their side effects (x == 1 or pytest.fail(), conditional expressions) and comparisons inside calls or assignments are not reported.

Noncompliant code example

def test_sum():
    result = add(1, 2)
    result == 3  # Noncompliant

Compliant solution

def test_sum():
    result = add(1, 2)
    assert result == 3
