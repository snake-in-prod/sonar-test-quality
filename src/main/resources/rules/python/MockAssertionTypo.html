A mock creates any attribute on access. A misspelled assertion (assert_called_onec) or an assertion name without its assert_ prefix (called_once_with, has_calls) is just another child mock: calling it records a call and checks nothing.

Why is this an issue?

The test passes whether the code under test called the mock or not. Recent Python versions raise AttributeError for some of these names, older ones and other mock libraries stay silent.

Noncompliant code example

m.assert_called_onec()
m.called_once_with(1)

Compliant solution

m.assert_called_once()
m.assert_called_once_with(1)
