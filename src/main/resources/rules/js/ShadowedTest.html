Two tests with the same literal name in one describe block.

Why is this an issue?

Test reports, -t filters and snapshot keys use the full test name, so one of the two tests is hidden or overwrites the results of the other. It is usually a copied test whose name was not updated, so the case it was meant to check is not named anywhere.

Noncompliant code example

it('saves the user', () => { ... });
it('saves the user', () => { ... }); // Noncompliant

Compliant solution

it('saves the user', () => { ... });
it('saves the user when offline', () => { ... });
