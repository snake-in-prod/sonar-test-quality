A matcher that cannot fail on the value it is given checks nothing: toBeTruthy() or toBeDefined() on a literal, an array or object, a function or a new object, on an unawaited findBy promise or on an array from queryAllBy / querySelectorAll / filter; toBeDefined() on a query that returns null when nothing matches; a value compared with itself.

Why is this an issue?

An empty array is truthy, a promise is truthy, and null is defined. The test passes even when the element is missing or the list is empty.

Noncompliant code example

expect(screen.queryAllByRole('row')).toBeTruthy();
expect(screen.queryByText('Saved')).toBeDefined();
expect(screen.findByText('Saved')).toBeTruthy();

Compliant solution

expect(screen.queryAllByRole('row')).toHaveLength(2);
expect(screen.queryByText('Saved')).not.toBeNull();
expect(await screen.findByText('Saved')).toBeTruthy();
