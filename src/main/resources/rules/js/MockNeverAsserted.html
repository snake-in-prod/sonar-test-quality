A jest.fn() or vi.fn() stored in a variable and passed to the code under test, but never asserted on.

Why is this an issue?

Naming a mock and handing it to the component usually means the test meant to check that it is called. Without an assertion the test passes even when the callback is never called or is called with the wrong arguments.

Noncompliant code example

const onSave = jest.fn(); // Noncompliant
render(<Form onSave={onSave} />);
await user.click(screen.getByRole('button'));

Compliant solution

const onSave = jest.fn();
render(<Form onSave={onSave} />);
await user.click(screen.getByRole('button'));
expect(onSave).toHaveBeenCalledWith({ name: 'Ann' });
