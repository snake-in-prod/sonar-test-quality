A getBy* or queryBy* query right after a user-event v14 action that is not awaited.

Why is this an issue?

The actions of userEvent.setup() return promises and dispatch their events later. A synchronous query on the next statement runs before the action happened: it checks the screen from before the action, so it either fails or passes for the wrong reason.

Noncompliant code example

user.click(screen.getByRole('button'));
expect(screen.getByText('Saved')).toBeInTheDocument(); // Noncompliant

Compliant solution

await user.click(screen.getByRole('button'));
expect(await screen.findByText('Saved')).toBeInTheDocument();
