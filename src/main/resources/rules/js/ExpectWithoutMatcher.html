An expect(...) that is never finished with a matcher, or whose matcher is not called, checks nothing: Jest and Vitest only fail when a matcher runs.

Why is this an issue?

The test looks like it verifies the value, but it passes whatever the value is. A forgotten matcher, a trailing .resolves or .not, or a matcher without parentheses (.toBeTruthy) are all silent.

Noncompliant code example

expect(user.name);
expect(save(user)).resolves;
expect(isValid(user)).toBeTruthy;

Compliant solution

expect(user.name).toBe('Ada');
await expect(save(user)).resolves.toBeUndefined();
expect(isValid(user)).toBeTruthy();
